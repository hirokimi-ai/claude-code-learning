プログラミング初心者向けの準備

Claude Code は日本語で頼むだけでも使えます。ただ、下の3つ（ターミナル・Git・Python）を少し知っておくと、つまずきが大きく減ります。わからない言葉は Claude にそのまま「〇〇ってなに？」と聞くのが一番早いです。

まずはこれ（1〜2時間でOK）

  • Claude Code 101（Anthropic Academy）公式・無料Claude Code のいちばん最初の公式入門コース
  • Mac ターミナル入門（初心者向け）日本語「黒い画面」の開き方、cd・ls などの基本コマンド、パスの考え方
  • ターミナルとは？（TECH CAMP）日本語そもそもターミナルが何なのかをやさしく解説

Git（変更履歴の管理）

  • サルでもわかる Git 入門日本語イラスト付きで Git の考え方を解説する定番サイト。Claude が「コミットしました」と言ったときの意味がわかるようになります

Python（AIエージェント作りに必要）

  • Progate日本語・一部無料ブラウザだけでスライド＋演習。最初の一歩に最適。Python・Git・コマンドラインのコースあり
  • ドットインストール日本語・一部無料3分動画でサクサク学べる
  • キノコード（YouTube）日本語Python 入門の動画がとても丁寧
  • しまぶーのIT大学（YouTube）日本語プログラミングの基礎を初心者向けに解説
  • freeCodeCamp 日本語版「Python 入門」日本語・無料環境構築から基本文法、クラスまで通しで学べる講座
  • Python 公式チュートリアル（日本語）Progate などの後に、辞書代わりに

よく出てくる用語ミニ辞典

ターミナル
文字でパソコンに命令する画面。Claude Code の CLI 版はここで動く
コマンド
ターミナルに打ち込む命令（例：ls＝ファイル一覧、cd＝フォルダ移動）
ディレクトリ / パス
ディレクトリ＝フォルダ。パス＝ファイルの住所（例：/Users/名前/claude）
リポジトリ
Git で管理されているプロジェクトのフォルダ。GitHub に置くとネット上で共有できる
コミット / プッシュ
コミット＝変更をセーブポイントとして記録。プッシュ＝それを GitHub に送る
CLAUDE.md
Claude に毎回読ませるメモ。「このプロジェクトのルール」を書いておくファイル
プロンプト
AI への指示文
コンテキスト
AI がいま覚えている会話や情報の量。いっぱいになると性能が落ちるので /clear でリセット
API / API キー
プログラムから AI を呼び出す窓口と、そのための合言葉（パスワード）。人に見せてはいけない
MCP
Claude を外部サービス（GitHub、Slack、データベースなど）とつなぐための共通規格
プラグイン / スキル / Hooks
Claude Code の拡張機能。スキル＝手順書、Hooks＝決まったタイミングで自動実行する処理、プラグイン＝それらの詰め合わせ
エージェント
AI が自分で考えて道具（ツール）を使い、ゴールまで繰り返し作業する仕組み
SDK
プログラムを作るための部品セット。Agent SDK ＝ エージェントを作る部品セット
